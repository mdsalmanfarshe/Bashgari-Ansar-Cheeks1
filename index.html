ফায়ারবেস সিকিউরিটি রুলস (Firebase Security Rules)

প্রজেক্ট এডমিনিস্ট্রেটর সালমান ফারশী-এর নিয়ন্ত্রণে সিকিউরিটি নিশ্চিত করতে নিচের Firestore ও Storage রুলস ফায়ারবেস কনসোলে পেস্ট করুন:

Cloud Firestore Security Rules: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Check if user is Super Admin Salman Farshi
    function isAdmin() {
      return request.auth != null && (
        request.auth.token.email == 'salman.farshi@banshgari.org' ||
        request.auth.uid == 'ADMIN_SALMAN_FARSHI'
      );
    }

    match /artifacts/{appId}/public/data/members/{memberId} {
      allow read: if true; // Verification portal allows public status search
      allow create: if request.auth != null; // Self registration
      allow update, delete: if isAdmin(); // Only Admin can approve/edit/delete
    }
  }
}

১. ফায়ারবেস (Firebase) সেটআপ ও সংযোগ পদ্ধতি

  1. Google এ গিয়ে Firebase Console এ প্রবেশ করুন এবং একটি নতুন প্রজেক্ট তৈরি করুন (নাম দিন: banshgari-ansar-vdp)।
  2. Authentication সেকশনে গিয়ে Email/Password সাইন-ইন এনাবল করুন।
  3. Firestore Database তৈরি করুন এবং টেস্ট মোডে শুরু করে সিকিউরিটি রুলস মডিউলের কোডটি বসিয়ে দিন।
  4. Project Settings থেকে Web App যুক্ত করে firebaseConfig অবজেক্টের API Key, AuthDomain ইত্যাদি অ্যাপের কনফিগারেশনে বসিয়ে দিন।
